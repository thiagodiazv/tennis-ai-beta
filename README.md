# Tennis AI (beta)

## O que é

Um app de tênis para Android que **corta os ralis do seu vídeo**: você grava a aula ou a partida, e o app separa
cada rali para você rever e compartilhar. É um app **experimental**, em teste: pode ter erros, e sua opinião ajuda
a melhorar.

## Requisitos

- Celular **Android 11 ou mais novo**.
- **iPhone não é suportado.**

## Como instalar

1. No celular, abra este link: <https://github.com/thiagodiazv/tennis-ai-beta/releases/latest>
2. Na página, procure a seção **Assets** e toque em `tennis-ai-<versão>.apk` para baixar.
3. O Android vai avisar que o arquivo pode ser perigoso e pedir para permitir **"instalar apps desconhecidos"**
   para o navegador que você usou. Permita **só para essa instalação** (depois você pode desligar).
4. Abra o arquivo baixado e toque em **Instalar**.
5. Toque em **Abrir**. Pronto.

## Como gravar

- Coloque o celular no tripé ou no alambrado, atrás da linha de fundo, um pouco alto.
- Use a lente 0,5×, com a quadra inteira na imagem.
- Sem relógio: use "Importar vídeo" ou "Sem relógio" na Nova sessão.

## Mandar feedback

Na sessão, toque em **⋮ → Enviar ao desenvolvedor**. Escreva o que achou e, se quiser, marque **incluir o vídeo
(versão leve)**. Depois escolha por onde enviar: WhatsApp, e-mail, Drive...

Se o vídeo mostrar outras pessoas, envie só se elas concordarem.

## Atualizações

O app avisa no **Início** quando há versão nova. Instale a nova versão por cima da antiga: suas sessões ficam
guardadas.

## Privacidade

- Nada sai do seu celular sem você tocar em **Enviar**.
- O app só usa a internet para ver se há versão nova.
